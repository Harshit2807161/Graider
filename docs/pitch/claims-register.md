# Claims register for the Gr8r marketing site

Compiled 2026-10-12 against branch `pitch/website-and-campaign` at commit `39f5297` (the content modules were edited by the copy pass while this was written; anything changed after that commit is not covered). Every statement a visitor can read in `site/content/*.ts` was checked against the source named in the table. Kirtan reviews this before anything goes public.

How a status was given: **verified** only if the named source, opened in this pass, says it (the CBSE page images p04, p07 and p24 were also looked at; the repo code and docs were read, not just their summaries). **unverified**: no source found. **contradicted**: a source disagrees; the source is quoted. **policy promise**: how the team will behave, listed separately for Kirtan to approve. **fixed (wording)**: was unverified or contradicted; the site's sentence was changed on 2026-10-12 and the new wording is in the row.

Every verified claim has an entry in `site/content/claims.ts` (72 entries; ids are cited below as `claims: id`). Sources written `README` are `docs/evals/cbse-x-science-2025/README.md`; `review.json` is `docs/evals/cbse-x-science-2025/runs/2026-10-11-gpt-4.1-mini/review.json`. The table groups claims by page; where several sentences carry one claim they share a row.
